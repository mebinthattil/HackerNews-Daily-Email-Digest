YouTube Ad Punisher – Auto-reloads YouTube pages when an ad plays

440 points • by iantongeorge • 78 comments
Summary

YouTube Ad Punisher is a Chrome‑compatible extension that removes YouTube ads by automatically reloading the page when an ad is detected. It watches for the .ad-showing class, skip buttons, and ad overlays using a 500 ms interval and a MutationObserver, captures the current playback timestamp (video.currentTime) to sessionStorage, then reloads via location.replace() with an &t= timestamp parameter. After 1‑3 reloads the ad slot is usually empty; YouTube auto‑seeks back to the saved position, preserving playback. If three reloads fail, the extension redirects to the ad‑free mirror yout‑ube.com with &loop=0 to prevent looping.

Key features: - Automatic tab switching after three reloads to exploit Chrome’s background‑tab throttling. - Support for incognito mode, live streams (plain reload), and an ad‑history database logging advertiser, duration, skip text, video ID, and timestamp; exportable as JSON or CSV. - Minimal permissions (storage, tabs) limited to YouTube domains. - Installation via “Load unpacked” in Chrome/Brave/Edge/Opera or an experimental Safari AppleScript workflow.

The project is MIT‑licensed and intended to complement blockers like uBlock Origin and SponsorBlock without triggering YouTube’s anti‑adblock detection.

Intel One Mono font (2023)

537 points • by saikatsg • 77 comments
Summary

Intel One Mono is an open‑source monospaced font family aimed at low‑vision developers. It provides Light, Regular, Medium, and Bold weights, each with matching italics, covering over 200 Latin‑script languages. Distribution includes OTF/TTF for desktop, TTF for mobile, and WOFF/WOFF2 optimized for web; recommended minimum sizes are 7 pt (print) and 9 px (screen). OpenType features include programming ligatures (ss01‑ss03), an alternate “three” glyph (ss04), raised colon (ss11/ss12, salt), language‑specific shaping (ccmp, locl), superscript/subscript (sups, subs, sinf), and fraction numerator/denominator (numr, dnom). Activation in editors (VS Code, Sublime Text, IntelliJ) requires setting the font family and enabling desired stylistic sets via font‑ligature settings. Source files are provided in UFO format, organized into “instances” (per‑style OTF/TTF/WOFF sources) and “masters” (extreme weight outlines) with designspace XML for interpolation. Recommended editing workflow uses RoboFont 4.4, with Decompose + Autohint for OTF builds and Autohint for TTF/WOFF builds; true‑type hinting data resides separately and can be edited with Microsoft VTT.
