56 points • by allanrbo • 9 comments
Summary

The post describes a Jev‑style wrapper that lets LLMs (including multimodal models) return token‑level log probabilities for single‑token answers, enabling fast classification without full text generation. By appending max_completion_tokens: 1, logprobs: true, and top_logprobs to a Chat Completions request, the API returns the chosen token plus probabilities for alternative tokens, which can be mapped to multiple‑choice, boolean, or ordinal scores. The author extends Jev’s JSON format with an attachments field for base64‑encoded images, allowing vision queries such as “Is a person visible?” or “How bright is the scene?” The provided Python script captures webcam frames, encodes them as JPEG data URLs, sends them with the prompt to either a locally served llama.cpp model (Gemma‑4‑12B‑QAT) or OpenAI’s gpt‑6‑luna, and prints per‑frame results and FPS (≈1 fps on RTX 3090, ≈0.2 fps on OpenAI). Installation steps include downloading the GGUF model and multimodal projector, installing a CUDA‑enabled llama.cpp binary, and running the script via uv run. The wrapper normalizes log‑probabilities, handles missing tokens, and returns structured answers for each question type.
