Claude discovers a novel enzyme system with CRISPR-like repeats

636 points • by raahelb • 60 comments
Summary

Anthropic’s new life‑sciences team used Claude, a general‑purpose AI, to mine large DNA‑sequence databases for uncharacterized reverse transcriptases (RTs). Over 21 hours, roughly 950 Claude agents examined ~200 000 RTs, generated 3 500 candidate systems, and shortlisted 20 for detailed human‑readable reports—an effort that would take weeks to months for a specialist. One agent identified a jumbo‑phage RT accompanied by a long, evenly spaced DNA repeat array resembling a CRISPR locus and an adjacent accessory gene. The researchers term this novel system “array‑associated reverse transcriptases” (ART). Initial lab tests confirm that the repeat array is transcribed into distinct short RNAs, suggesting a programmable nucleic‑acid‑based function, though its precise activity remains unknown. The discovery was described in a pre‑print, with commentary from CRISPR pioneer Feng Zhang. Anthropic’s workflow combines AI‑driven hypothesis generation, automated literature and sequence analysis, and human experimental validation, and the group invites external collaborations to extend this approach.

Virtio-nvgpu: Near-native Nvidia GPU access inside a KVM guest

86 points • by WanjohiRyan • 12 comments
Summary

virtio‑nvgpu is an experimental virtio device enabling near‑native NVIDIA GPU access for headless KVM guests. It forwards NVIDIA kernel driver ioctls between guest and host at the driver ABI level, allowing the guest to run unmodified NVIDIA user‑mode libraries (Vulkan, OpenGL, CUDA, NVENC) with GPU buffers shared via mmap’ed windows. Benchmarks on an RTX 3060 (driver 595.99.02) show per‑frame latency within 2 % of bare metal for workloads >2 ms/frame; CPU cost matches the host, and only ~5–20 ioctl crossings occur per frame. Four simultaneous guests share the card evenly (≈103 fps total) without hitting NVENC limits. The architecture separates a GPL guest driver (kernel symbols) from a permissively‑licensed Rust device crate that handles descriptor translation, buffer bookkeeping, and event queues; a sandboxed isolate per guest is planned but not yet implemented. Supported driver ABI profiles span 535.129.03 to 595.71.05; older versions are rejected. Out‑of‑scope features include unified memory, physical scan‑out, MIG/SR‑IOV, and multi‑GPU scaling.
