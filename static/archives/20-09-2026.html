UTF-8000: Unlimited UTF-8

47 points • by vismit2000 • 16 comments
Summary

UTF‑8000 extends UTF‑8 by allowing arbitrarily long code units while preserving its self‑synchronizing architecture. Each byte begins with a self‑synchronization prefix: 0 for ASCII (single‑byte) and 11 for multi‑byte start bytes, while continuation bytes use 10. The start bits form a unary prefix (111…10) that indicates the total length n of the code unit; for n ≥ 8 the start bits are split across the first few bytes. Content bits occupy the remaining positions, yielding 5n + 1 content bits for n > 1 (7 bits for ASCII). Mandatory content bits (4 for 2‑byte units, 5 for longer units) guard against overlong encodings, ensuring a unique representation and preventing security issues. UTF‑8000 inherits UTF‑8’s two special cases—ASCII and 2‑byte units—and adds no new exceptions. Information rate approaches 62.5 % (5/8) as n grows. The design retains byte‑level self‑synchronization, enabling random access and error recovery without global context.
