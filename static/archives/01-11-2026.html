Summary

Laboratory analysis identified the grain as Triticum turgidum (Latin “swollen wheat”), known in English as poulard wheat, a heritage variety once cultivated in the Mediterranean but displaced by high‑yield modern cultivars. Grossi partnered with local bakeries, food‑science students, and the organic mill Molino Grassi to produce flour and bread, aligning with Italy’s 1990s slow‑food movement and current efforts to diversify crops for climate resilience.

TCP Use-After-Free: CVE-2026-98432 / CVSS 9.8

513 points • by oger • 42 comments
Summary

Linux kernels 4.4 → 7.3 contain CVE‑2026‑98432, a use‑after‑free in the IPv4 TCP handshake. An unauthenticated remote host can trigger the bug by sending a SYN with IP options; the kernel frees the saved options before all CPUs finish reading them, allowing memory leakage, out‑of‑bounds writes, or remote code execution. The issue affects any Linux server that accepts IPv4 TCP connections, including containers, and is exploitable without credentials on systems with a multipath‑TCP (MPTCP) listener—Go programs enable MPTCP by default. Fixed upstream kernels are 5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10, and 7.3; back‑ported fixes exist in Debian 12/13, SUSE SLES 16, Oracle UEK, Amazon Linux 2/2023, and AlmaLinux testing, but Ubuntu and RHEL kernels remain vulnerable as of 31 Oct 2026. The upstream patch replaces kfree() with kfree_rcu() for saved options and adds the same safeguard for request‑socket migration. Interim mitigations include nftables/iptables rules dropping IPv4 TCP packets with header length > 20 bytes and disabling MPTCP via sysctl. Anthropic reports a proof‑of‑concept exploit achieving root, but it has not been publicly released.
