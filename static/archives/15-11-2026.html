  • On a sparc64 NetBSD system, the primary disk wd0 is partitioned with a dedicated cgd partition d (type cgd) spanning cylinders 10404‑33287.

  • To verify passwords, embed a secondary disklabel inside the encrypted partition. Use the disklabel editor to create sub‑partition a, set the filesystem type (e.g., 4.4LFS or 4.2BSD), start offset 0, size $ (full space), then write the label.

Strictly monotonic timestamps and gapless sequences in Rust

8 points • by znano • 1 comments
Summary

tsoracle is a Rust‑implemented timestamp oracle that provides two services: strictly monotonic timestamps (get_ts) and gapless, dense sequences (get_seq) per named key. Both are durable and fault‑tolerant: the leader fsyncs a high‑water mark or per‑key counter, replicates it via pluggable consensus (built‑in OpenRaft and OmniPaxos drivers, with a trait for custom back‑ends), then hands out IDs locally for high throughput. Gapless sequences are non‑idempotent; failures return a SeqUncertain error to avoid silent retries. The system is crash‑safe—state is persisted before any ID is issued, and restarts never rewind. It includes a gRPC client with leader discovery, request coalescing, and reconnection, and emits Prometheus‑compatible metrics for allocator, leader, and request activity. tsoracle can run as a standalone CLI service, be embedded as a library, or deployed via Docker/Helm. The project is open‑source under Apache‑2.0, with fuzzing, fail‑point testing, and stress harnesses for hardening, and follows conventional contribution and release processes.
