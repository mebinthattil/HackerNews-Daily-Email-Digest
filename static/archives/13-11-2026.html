IceWM

203 points • by inatreecrown2 • 28 comments
Summary

IceWM is a lightweight X Window System manager focused on speed, simplicity, and minimal interference. Developed in C++ by Marko Maček since 1997, it offers a taskbar with pager, global and per‑window keybindings, dynamic menus, and full keyboard control (including Alt‑Tab switching). The manager supports multiple monitors via RandR and Xinerama, several focus models, manual window placement, autoraising, tooltips, DockApps, tabbed windows, and configurable keybindings. It is highly configurable and themeable, with over 450 downloadable themes; themes consist of settings and small images. IceWM is packaged for major Linux distributions (Debian, Ubuntu, Arch, OpenSUSE, Gentoo, Slackware, CentOS, antiX, NixOS) and most *BSDs, and is translated into roughly 36 languages. The latest stable release is 4.1.0 (2026‑08‑06), released under the GNU Library GPL. Installation can be performed from source tarballs or GitHub development clones, requiring standard X11 libraries and optional dependencies (e.g., imlib2, libpng). Bug reports and contributions are handled via GitHub.

Rust 1.100

706 points • by mbStavola • 37 comments
Summary

Rust 1.100.0 stabilizes several major features and introduces key Cargo improvements.

  • Never type (!) is now fully stable, usable in any position, with Infallible aliased to !. The fallback type changes from () to ! in pre‑2024 editions, a breaking change that may affect generic result handling.
  • Allocator API: the core Allocator trait and related types (Box, Vec, Arc, Rc) are stabilized, enabling custom allocators for Vec and Box.
  • DropGuard (core::mem::DropGuard) provides a convenient closure‑on‑drop helper, supporting dismiss to prevent execution.
  • Zero‑sized type creation: std::mem::conjure_zst offers a dedicated, unsafe way to instantiate ZSTs safely.
  • Cargo linting: unused_crate_dependencies warns about dead dependencies; cache layout now consistently hashes build configurations, reducing collisions.
  • Dependency cooldowns: min-publish-age lets registries enforce a waiting period before new crate versions are considered, configurable via .cargo/config.toml.

Additional stabilized APIs include numerous Allocator implementations, bool::toggle, Box::take/map, UnsafeCell helpers, string/array trim prefixes/suffixes, Vec::from_fn, and Windows process extensions.
