Linux from Scratch

155 points • by sippingabonedry • 19 comments
Summary

Linux From Scratch (LFS) is a project that supplies step‑by‑step instructions for building a custom Linux system entirely from source. The organization maintains several related subprojects:

  • LFS – the core book forming the base for all other projects.
  • BLFS (Beyond Linux From Scratch) – extends an LFS installation with additional software for a functional system.
  • ALFS (Automated Linux From Scratch) – provides tools to automate and manage LFS/BLFS builds.
  • MLFS (Multilib Linux From Scratch) – creates an LFS system capable of building and running 32‑bit binaries.
  • GLFS (Gaming Linux From Scratch) – builds on BLFS to add gaming support such as Steam or Wine.
  • SLFS (Supplemental Linux From Scratch) – offers further enhancements beyond BLFS.
  • Hints – a collection of documents for optional enhancements not covered in the main books.
  • Patches – a central repository of patches useful to LFS users.
  • LFS Editor’s Guide – outlines the LFS development process.
  • Museum – archives historic versions of LFS and BLFS.

Charts built for Chat

216 points • by thingsilearned • 25 comments
Summary

dbt Charts is an open‑source, YAML‑based language that moves chart definition out of traditional BI UIs and into code, enabling AI agents to generate and modify dashboards programmatically. It pairs SQL (the “what” of data) with YAML, Markdown, and Jinja to specify layout, styling, and interactivity, supporting over 1,100 configuration options across sixteen chart types and composable charts. A single YAML file can render to SVG, HTML, PNG, PDF, or terminal output via the CLI, and can be served as a static site. When used inside a dbt project, chart files sit alongside model files, allowing version‑controlled changes, CI validation, and automatic failure on broken references through dbt’s manifest and Semantic Layer support (planned). The system includes strict validation of both YAML and SQL and visual checks that surface layout issues before rendering. A hosted beta, dbtCharts.com, adds warehouse connections, conversational analytics, visual editing, version history, and permissioned sharing while keeping the YAML source as the single source of truth. The project is licensed under Apache 2.0.
