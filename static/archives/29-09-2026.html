Using any C++ library in Godot

28 points • by czoido • 5 comments
Summary

Godot (MIT‑licensed) supports native C++ extensions via GDExtension, which loads a shared library (.dll/.so/.dylib/.wasm) at runtime. The official godot‑cpp bindings wrap the low‑level C API, providing C++ classes for all engine types; extensions derive from these classes and become regular nodes visible in the editor and usable from GDScript. Since godot‑cpp 10.0, a single release works with any Godot 4.3+ version by selecting an api_version option, and three build targets exist (template_debug, template_release, editor) that determine which library Godot loads based on the .gdextension file tags.

Building extensions traditionally requires compiling godot‑cpp and every third‑party library for each platform. ConanCenter now provides a godot‑cpp package, making it a regular Conan dependency. Projects specify api_version and target options, and Conan resolves and builds matching binaries for all platforms, including any additional libraries (e.g., flecs ECS).

The article demonstrates a GDExtension that creates a Swarm Node2D, uses flecs to simulate 100 000 particles, and renders them via a MultiMeshInstance2D. A Conan recipe declares godot‑cpp and flecs, CMake links them into a single shared library, and a single conan build command produces the extension for the selected target. This workflow simplifies cross‑platform distribution and integration of arbitrary C++ libraries into Godot projects.

Phyllotaxis: An audio-reactive LED display

144 points • by evakhoury • 17 comments
Summary

The project implements an audio‑reactive LED sculpture based on the phyllotaxis pattern, where points are placed on a radial line and rotated by multiples of the golden ratio to form a sunflower‑like cloud. Voronoi tessellation of these points generates cell shapes that house individual addressable RGB LEDs. Using CadQuery, the author creates 3D models: each cell is offset, extruded, and subtracted from a total volume, then a hole for the LED is cut. The model is split into quadrants for 3D printing, post‑processed in FreeCAD, and fitted with translucent mulberry paper for diffusion. An STM32 “blackpill” drives 89 LEDs via a custom SPI Neopixel driver; LED positions are stored in a lookup table and animated with fragment‑shader‑style code (e.g., radial sine spirals). An I2S MEMS microphone (INMP441) provides digital audio, processed with ARM CMSIS FFT and multiband gain to modulate brightness. Subsequent revisions replace the 3D‑printed backplate with five identical PCBs, move to an ESP32 with Rust firmware, and expose a local web UI for uploading WebAssembly sketches. Future work targets easier soldering, protective acrylic, and modular paper facings.

Summary

California wine grape growers face a sharp demand decline, with wine sales falling over 20% in five years and U.S. case shipments down 23% from 2020 to 2025. Prices for grapes have dropped, prompting removal of roughly 25% of the state’s ~600,000 vineyard acres. About half of this year’s crop entered harvest without buyer contracts, compared with 70‑80% contracted in a typical year. Growers such as Bill Berryhill (Berryhill Family Vineyards, Lodi) are leaving 200 of 500 acres unsold and plan to rip out 50 acres, accepting losses or discarding grapes. Allied Grape Growers reports that uncontracted grapes must often be sold at a loss for concentrated syrup. The market contraction is linked to aging baby‑boomer consumers, reduced alcohol consumption among younger adults, competition from craft beer, spirits, canned cocktails and cannabis, and lower global wine demand. Export options are limited by higher U.S. production costs and declining worldwide consumption. Consequently, vineyard closures are affecting farm labor and local economies.
