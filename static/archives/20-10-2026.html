Nordwand Mono – A monospace font for coders and adventurers

184 points • by noriax86 • 31 comments
Summary

Nordwand Mono is a compact monospace neo‑grotesque font created from scratch with Python for coding environments. It blends the classic proportions of Adrian Frutiger’s Univers with the metrics of JetBrains Mono, and its name references Swiss typographic heritage. Design influences include Univers, Apple’s SF Pro & SF Mono, Sharp Type’s Alpes Mono, and Dalton Maag’s Ubuntu Mono. The project provides alternative character sets selectable via OpenType feature tags, and includes two ligatures (“->” and “=>”), with possible future expansion. Users can generate custom builds by editing config.example.yml, visualizing individual glyphs (python -m visualize --config config.yml <glyph_id>), and compiling the full font (python -m generate_font --config config.yml), which outputs to ./custom-fonts. The README warns that altering metrics may require glyph adjustments and offers no guarantee of visual quality after such changes.

OpenBSD 8.0

260 points • by privong • 14 comments
Summary

OpenBSD 8.0 provides platform‑specific installation media and procedures. For α, amd64, i386, and arm64, a bootable CD (install80.iso) can be written; amd64 and i386 also support USB boot from install80.img or a miniroot image, and network PXE installation where CD/USB are unavailable. armv7 requires a system‑specific miniroot on an SD card with serial‑console access. hppa installs via network boot per INSTALL.hppa. landisk uses a miniroot image written to the CF or disk start. luna88k copies boot and bsd.rd to a Mach/UniOS partition and boots from the PROM. macppc boots from CD or via Open Firmware commands. octeon boots bsd.rd over DHCP/TFTP after serial connection. powerpc64 and riscv64 install from a USB stick (riscv64 also needs the board’s microSD card). sparc64 can boot from CD, floppy, swap‑partition miniroot, or network as described in INSTALL.sparc64; floppies must be error‑free.

The OpenBSD ports tree is distributed as a tar.gz archive; it can be extracted to /usr and updated via anonymous CVS (e.g., cvs -d anoncvs@server.openbsd.org:/cvs update -Pd -rOPENBSD_8_0). Prebuilt packages are also available on mirrors. The ports‑related mailing list is ports@openbsd.org.

Restoration of Retinal Regenerative Potential

45 points • by Kaibeezy • 0 comments
Summary

Retinal injury in mice induces a marked increase of Prox1 protein in Müller glia (MG) without up‑regulating Prox1 mRNA, indicating protein acquisition from neighboring neurons. Using RNAscope, FACS‑sorted MG, and a Prox1‑EGFP reporter, the study showed that MG lack endogenous transcription at the Prox1 locus yet accumulate the protein after photoreceptor degeneration (MNU, light, NMDA). Genetic deletion of Prox1 in bipolar cells (Chx10‑CreERT2) lowered MG Prox1 levels and significantly raised EdU‑positive MG, demonstrating that neuronal Prox1 suppresses MG proliferation. Intravitreal delivery of FLAG‑tagged recombinant Prox1 to injured retinas reversed this effect, reducing MG proliferation and increasing microglial proliferation; the same manipulation in zebrafish MG also decreased Ascl1a‑positive MGPCs. Blocking extracellular Prox1 with an anti‑Prox1 scFv expressed via AAV2 restored MG proliferation in injured mice. Single‑cell RNA‑seq of Prox1‑depleted MG identified activated clusters and a trajectory from resting MG to RPC‑like states, with up‑regulation of Gadd45a, Hbegf, Notch1 and Hes1, confirming a transition toward a regenerative phenotype when intercellular Prox1 transfer is disrupted.

159 points • by emot • 24 comments
Summary

In early October 2026 French supermarket refrigerators were forced into defrost mode, heating to 50 °C, causing food loss and fires. The attack targeted Danfoss refrigeration controllers (models AK‑SM 800, AK‑SM 800A, AK‑SC 355) whose web dashboards were exposed on the public IPv4 Internet. Weekly IPinfo scans showed 1,331 French dashboards—53 % of the global total of 2,528—while 85 % ran software with known vulnerabilities; only 195 (15 %) had all published fixes. Most exposed devices had been online since at least March 2026, with 1,019 addresses unchanged over six months. After the incident, 76 % of French dashboards disappeared by October 14, indicating operators unplugged them rather than patching. Similar exposures existed in 69 other nations, notably Poland, the US and Portugal. CERT‑FR advises removing controllers from the public Internet, using VPNs for contractor access, updating firmware, enforcing strict security settings, and changing default passwords. The attacker’s identity and entry method remain unknown.

An ad-free Android TV

195 points • by CraftThatBlock • 16 comments
Summary

The guide explains how to eliminate Google TV ads and replace the default interface on Android TV devices. It uses the following components:

  • Projectivy Launcher as a custom home screen, showing only installed apps.
  • SmartTube (sideloaded) to replace the official YouTube app, providing ad‑free playback and built‑in SponsorBlock.
  • Wholphin as the Jellyfin client.
  • Button Mapper to remap the remote’s YouTube button to launch SmartTube.

Setup steps:
1. Install Projectivy, Wholphin, Button Mapper from Play Store; sideload SmartTube.
2. Enable Developer options, turn on Wireless (or USB) debugging, pair via ADB.
3. Disable the stock launcher packages (com.google.android.apps.tv.launcher, com.google.android.tungsten.setupwraith) and set Projectivy as the home activity using adb shell pm set-home-activity.
4. Uninstall or disable the official YouTube TV app (adb uninstall or pm uninstall --user 0).
5. Enable required accessibility services, grant WRITE_SECURE_SETTINGS to Button Mapper, and map the YouTube button to SmartTube.
6. Optional: reduce animation scales and disable unused Google apps via ADB.

All changes are reversible with pm enable or cmd package install-existing. The result is an ad‑free Android TV experience with a streamlined launcher and remote controls.
