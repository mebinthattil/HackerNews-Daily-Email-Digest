Show HN: Sphinx – A hook that quizzes you on your AI's code before shipping

97 points • by critiquebrowser • 21 comments
Summary

Sphinx is a Git hook that adds an “understanding check” to the push workflow for agent‑assisted development. When a developer or AI coding agent pushes changes, Sphinx pauses the push and presents a scenario‑based question derived from the diff (e.g., handling Stripe webhook retries). The user must answer; an incorrect response triggers a learning loop, while a correct answer allows the push to continue. The tool operates with minimal token usage and can interface with any OpenAI‑compatible endpoint, including Codex, Claude, Cursor, OpenCode, and Pi. Answers never reach the coding agent, and environment files or secrets remain hidden. A “yolo” mode permits pushes to proceed automatically, logging any skips. Installation is via npm (npm install -g sphinx-understand) on Node 22.19+ across macOS, Linux, or WSL, after which normal git push commands invoke the Sphinx checks. The system aims to ensure developers understand the functional impact of code before it ships.

Bleached corals thrive within days when touching healthy neighbour

424 points • by alkyon • 16 comments
Summary

Scientists demonstrated rapid reversal of coral bleaching by physically joining bleached fragments with healthy ones from the same genet. In laboratory trials using Pocillopora damicornis, ten paired fragments (one bleached, one healthy) were set up; five pairs were allowed to touch, forming a tissue bridge, while five were separated by millimetres. In touching pairs, the bleached fragments regained color within eight weeks, with symbiont populations doubling every four days and full recovery occurring after a week of contact even when later isolated. Separated pairs showed no recovery and died after ~20 weeks. Microscopy confirmed that fusion and symbiont transfer required genetic identity; fragments from different individuals or species did not fuse or transmit algae. The findings suggest a potential, scalable method for restoring bleached corals by leveraging intra‑genet tissue connectivity to re‑establish Symbiodiniaceae symbiosis.

Fun Extending the C Preprocessor

17 points • by david2ndaccount • 2 comments
Summary

The snippet demonstrates a C‑preprocessor technique for applying a macro to each argument in a variadic list. It defines:

  • CAT/CAT_ for token concatenation.
  • NARG and NARG_ to count the number of arguments, using __VA_OPT__ to handle empty variadic lists and a trailing sequence 8,7,…,0.
  • A series of MAP_n macros (MAP_0 … MAP_8) that recursively invoke a user‑supplied macro m on each argument, chaining calls until the list is exhausted.
  • __map selects the appropriate MAP_n by concatenating MAP_ with the count from NARG.

An example defines PRINTINT(x) as printf(#x " = %d\n", x); and calls __map(PRINTINT, 1, 2, 3, 4, x, y, z). After preprocessing, the code expands to separate printf statements for each argument, printing their names and values. The approach works for up to eight arguments and illustrates how variadic macros and token‑pasting can emulate a map operation in the C preprocessor.
