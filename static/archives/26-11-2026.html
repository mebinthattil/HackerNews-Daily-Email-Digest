Intel One Mono font

145 points • by saikatsg • 28 comments
Summary

Intel One Mono is an open‑source monospaced typeface optimized for developer readability and low‑vision use. It supports over 200 Latin‑script languages and offers four weights (Light, Regular, Medium, Bold) with matching italics. Font files are available as OTF/TTF for desktop and mobile, and as WOFF/WOFF2 for web; recommended minimum sizes are 7 pt (print) and 9 px (screen). Key OpenType features include programming ligatures (ss01) and alternate forms (ss02–ss04), raised colon (ss11, ss12, salt), language handling (ccmp, locl), superscripts/subscripts (sups, subs, sinf) and fractions (numr, dnom). Activation instructions are provided for VS Code, Sublime Text, and IntelliJ. The repository contains editable UFO source files (instances and masters) with .fea feature files; instances are split into PostScript (for OTF) and TrueType (for TTF/WOFF/WOFF2) subfolders. Editing workflows recommend RoboFont 4.4, Skateboard for interpolation, and VTT for TrueType hinting. Build settings suggest “Decompose” + “Autohint” for OTF and “Autohint” only for TTF/WOFF/WOFF2, using Release Mode. Issues may be opened for edit requests.

1Password Security Incident

1499 points • by lxhrstn • 125 comments
Summary

On Nov 19 2026 1Password detected that an attacker compromised an employee’s corporate GitHub account, used it to obtain source code and push malicious code to backend services, and downloaded administrative data for a subset of users. Exfiltrated data included names, email addresses, account/user IDs, creation and last‑sign‑in timestamps, public keys, Secure Remote Password (SRP) parameters, invitation/recovery tokens, and non‑secret internal metadata. No vault contents, vault‑protecting keys, account passwords, Secret Keys, recovery keys, or app/extension code were accessed. The attacker also copied private repository code and accessed the CI/CD pipeline; all credentials potentially exposed have been rotated. Mitigations performed: disabled the compromised GitHub account, revoked stolen tokens, rotated internal credentials, extended invitation/recovery codes from six‑digit numeric to ten‑character alphanumeric, tightened GitHub/CI/CD/endpoint controls, added new detections, and engaged independent security auditors. Users are advised to watch for phishing, keep passwords and Secret Keys secure, and report suspicious activity to support@1password.com. 1Password emphasizes that vault data remains encrypted and inaccessible to attackers.

Lions' Commentary on Unix: Why It Was Secretly Copied for 20 Years

133 points • by joonehur • 12 comments
Summary

John Lions, while teaching operating systems at the University of New South Wales, created “Lions’ Commentary on UNIX 6th Edition” to give students direct access to Unix source code, arguing that source study was essential for OS education. In 1979 AT&T’s Version 7 license restricted classroom use of Unix source, forcing the commentary’s distribution to be tightly controlled. For two decades students relied on unauthorized photocopies, which nonetheless enabled a generation to understand and develop operating systems. The commentary, later reconstructed as a PDF and also available in print (ISBN 1‑57398‑013‑7), includes the full V6 source and a foreword by Dennis Ritchie. The Unix V6 source itself can be obtained from the TUHS archive. The work is frequently cited in histories of Unix and in teaching projects such as MIT’s xv6, illustrating its lasting influence on OS education.

Minipg: PostgreSQL as a Single Executable

172 points • by rguiscard • 15 comments
Summary

minipg packages PostgreSQL as a single executable that manages its own database directory (e.g., app.pgdb) containing data, configuration, credentials, and the PostgreSQL version. It embeds Docker Hub’s postgres:18‑alpine image and runs it via the h9 Plan 9‑based hypervisor, which executes Alpine’s PostgreSQL binaries directly on the host without a Linux kernel, VM, or Docker. A server process is started on demand and stops when idle; commands such as minipg app.pgdb or minipg app.pgdb "select 1" invoke psql, pg_dump, etc., each in a short‑lived h9 instance. The tool provides utilities for initializing, serving, dumping, restoring, and running applications with a generated DATABASE_URL. The Linux binary is statically linked, requiring no special privileges, and can be used in CI pipelines. The source is MIT‑licensed on GitHub, built with Zig 0.16, and includes a web demo that runs in browsers supporting JavaScript Promise Integration. Performance is roughly half that of native PostgreSQL, and the project is considered early‑stage.
